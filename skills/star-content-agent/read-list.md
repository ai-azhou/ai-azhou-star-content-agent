# 翻收藏列表

适用于这几种情况：setup 第 4 步摸清和翻列表、daily-run 第 7 步拉新收藏，以及其他需要从收藏列表里拿条目和最新链接的时候。

**原则：以页面上看得到的为准，接口数据只用来补字段、做交叉核对。** 原因是 OpenCLI 2.0 的抓包（`browser network`）有几个坑，在本地测试页上实测确认过：

- **没有新请求时，会返回旧数据。** 每次只返回上一次读取之后新抓到的请求；一条新请求都没有时，它不返回空，而是把上一批原样返回，只在输出里标 `cache_reused: true`。
- **key 会被新一批顶替。** 同一个接口每一批的 key 名都一样（同一批里重复的编号成 `key#2`、`key#3`），缓存又只保留最新的一批。用上一批的 key 再去取正文，拿到的是新一批的数据，而且不报错。
- **可能漏掉首屏。** 抓包没开起来时，OpenCLI 会在页面加载完以后才补装拦截，首屏的请求整个漏掉。
- **页面上读链接更可靠。** 用 `find` 读页面上的链接，在测试里每一步都准确，而且带完整链接（小红书的 xsec_token 也在）。

## 每翻一批，做下面几步

1. **打开或往下翻。**
   - 第一次：打开收藏夹入口；
   - 以后每次：`门卫 <平台> scroll down --amount 3000 --session sca-fav`。
   - 门卫会自动等够请求间隔。滚完以后，可以用 `门卫 <平台> wait selector "<列表项选择器>" --session sca-fav` 等列表渲染出来；不要用 `wait time`。
2. **读页面。**
   - 运行 `门卫 <平台> find --css "<列表链接选择器>" --limit 500 --session sca-fav`。
   - 从每一条的 `attrs.href` 里取笔记 id 和完整链接，`text` 就是标题。
   - 按 id 去重，累计到这次运行的「已看到」集合里。有的网站会把滚出屏幕的条目从页面上删掉，所以要累计，不能只看当前这一屏。
   - 选择器以 site-notes.md 为准；第一次可以先试：小红书 `a[href*="xsec_token"]`，抖音 `a[href*="/video/"]`。
   - 实测小红书的收藏页是**虚拟列表**：页面上始终只有大约 30 张卡片，往下滚时旧卡片会被换掉。所以不能看页面上有多少条，要按 id 累计。卡片上的 `data-note-id`、`data-index`（从 0 开始的序号）能帮你判断翻到了第几条。小红书每批加载 10 条。
   - **`find` 报找不到元素（selector_not_found），或者一条都没读到**，不要直接当成「没有收藏」或「到底了」：
     1. 先运行 `门卫 <平台> get url --session sca-fav`，确认这个标签页还在收藏页上。会话有时会失效，标签页已经不是原来的页面了，实测碰到过。
     2. 不在收藏页：重新打开收藏夹入口（算一次请求），从头再来。
     3. 还在收藏页、页面上也确实有收藏：说明选择器不对了，按网站改版处理（见 daily-run 第 7 步）。
3. **读接口**（可选，用来补类型、作者这些页面上不好读的字段）。运行 `门卫 <平台> network --filter <字段名> --session sca-fav`，然后：
   - 输出里有 `cache_reused: true`：这一批没抓到新请求，**忽略这次结果**。
   - 没有这个标记：**马上**把这一批的每一个 key（包括 `#2`、`#3`）各取一次正文：`门卫 <平台> network --detail "<key>" --session sca-fav`。要在下一次滚动、下一次 `network` 之前取完；不要回头用以前的 key。
   - 正文标了 `body_truncated`：这一批不完整，只用页面上读到的。
4. **交叉核对。**
   - 接口里有、页面累计集合里没有的：再读一次页面。还是没有，就以接口为准入库，在 run.log 记「页面没显示 N 条」。
   - 页面上有、接口里没有的：以页面为准入库，类型、作者先空着，读内容时再补。这很常见，说明这一批接口没抓到。
   - 两边的差异计数写进 run.log，方便以后调整 site-notes.md。
5. **判断是不是到底了。** 连续两次滚动后都同时满足下面两条，才算到底：
   - 页面累计集合没有变多（或者页面上最大的序号不再增长）；
   - 接口说 `has_more` 为 false，或者接口这次是 `cache_reused`。

   只有接口说到底、页面还在变多的，不算到底。
6. **翻完关掉标签页。**

## 写进 site-notes.md 的

列表链接的选择器、链接里 id 的位置、列表项的选择器、接口地址的特征和字段名、每批大概多少条、两边通常差多少。只记结构，不抄页面里的句子。
